# Top AI Academic Papers List
[![Subscribe on YouTube](https://img.shields.io/badge/YouTube-Subscribe-red?style=for-the-badge&logo=youtube&logoColor=white)](https://youtube.com/channel/UC_lqYWX_kD00D7yiZcrtBng/) [![Connect on LinkedIn](https://img.shields.io/badge/LinkedIn-Connect-blue?style=for-the-badge&logo=linkedin&logoColor=white)](https://www.linkedin.com/in/louislhotte/)


This collection brings together the most useful AI research papers from classics (~2017) to frontier work in 2026, selected for Forward Deployed profiles building real-world AI systems. 
All papers listed have been read and approved as useful.

| Paper Title | Description | Date | arXiv Link |
| --- | --------------------------------------- | --- | --- |
| **A Programming Paradigm for Spatiotemporal Composability** | Introduces a programming paradigm for dynamically composable software and agent systems. Formalizes reversible effects and reactive dependencies so components can be safely added, removed, and reconfigured at runtime, and implements the approach in the Cordis framework. | 2026-08 | [https://arxiv.org/abs/2608.25512](https://arxiv.org/abs/2608.25512) |
| **Stealing Reasoning Traces from Proprietary LLM APIs** | How a team managed to steal reasoning from model providers, using the stateless not-so-secure encrypted CoT and feeding them to lower level models (e.g. Haiku) of same provider | 2026-08 | [https://www.alphaxiv.org/pdf/2608.09867v1](https://www.alphaxiv.org/pdf/2608.09867v1)
| **Microservice Architecture Patterns for Scalable Machine Learning Systems** | A practical paper on designing scalable, production-ready ML systems using microservices. Addresses deployment, orchestration, and operational challenges for real-world AI stacks. | 2026-03 | [https://arxiv.org/abs/2603.13672](https://arxiv.org/abs/2603.13672) |
| **DeepSeek-V3.2: Pushing the Frontier of Open Large Language Models** | A major technical report on a state-of-the-art open-source Mixture-of-Experts (MoE) model that advances the frontier of accessible LLMs with competitive performance. | 2025-12 | [https://arxiv.org/abs/2512.02556](https://arxiv.org/abs/2512.02556) |
| **Less is More: Recursive Reasoning with Tiny Networks (TRM)** | Samsung's 7M-parameter recursive reasoning model that outperforms Gemini 2.5 Pro, o3-mini, and DeepSeek R1 on ARC-AGI and logic puzzles through iterative self-refinement loops. | 2025-10 | [https://arxiv.org/abs/2510.04871](https://arxiv.org/abs/2510.04871) |
| **DeepSeek-R1 Technical Report** | Introduces a model that achieves strong reasoning capabilities via large-scale reinforcement learning. This paper sparked a major shift toward RL-first training pipelines. | 2025-01 | [https://arxiv.org/abs/2501.12948](https://arxiv.org/abs/2501.12948) |
| OmniBench: Towards The Future of Universal Omni-Language Models | Introduces a benchmark for evaluating omni-language models across text, image, and audio, testing whether models can jointly reason over multiple modalities rather than handling each independently. | 2024-09 | [https://arxiv.org/abs/2409.15272](https://arxiv.org/abs/2409.15272) |
| PubTables-1M: Towards Comprehensive Table Extraction From Unstructured Documents | Introduces a dataset of nearly one million richly annotated scientific tables for table detection, table structure recognition, and functional analysis, enabling robust document-understanding and table-extraction systems. | 2021-10 | [https://arxiv.org/abs/2110.00061](https://arxiv.org/abs/2110.00061) |
| **LoRA: Low-Rank Adaptation of Large Language Models** | Introduces a highly efficient parameter-efficient fine-tuning method that injects trainable low-rank matrices, drastically reducing the number of parameters needed for adaptation. | 2021-06 | [https://arxiv.org/abs/2106.09685](https://arxiv.org/abs/2106.09685) |
| **Language Models are Few-Shot Learners (GPT-3)** | Demonstrates that scaling to 175B parameters enables strong few-shot and in-context learning, revolutionizing how we interact with and deploy LLMs. | 2020-05 | [https://arxiv.org/abs/2005.14165](https://arxiv.org/abs/2005.14165) |
| **Mixtral of Experts** | Introduces Mixtral 8x7B, a sparse Mixture-of-Experts (MoE) model where a router selects 2 of 8 experts for each token. A key paper for understanding how MoE architectures scale model capacity while keeping inference compute relatively low. | 2024-01 | [https://arxiv.org/abs/2401.04088](https://arxiv.org/abs/2401.04088) |
| **Scaling Laws for Neural Language Models** | Provides empirical power-law relationships between model size, dataset size, compute, and performance, guiding the scaling strategies used in modern frontier models. | 2020-01 | [https://arxiv.org/abs/2001.08361](https://arxiv.org/abs/2001.08361) |
| **The Bitter Lesson** | A foundational essay by Rich Sutton arguing that general methods leveraging computation outperform hand-engineered approaches. A core principle behind scaling laws and modern AI development. | 2019-03 | [https://arxiv.org/html/2410.09649v1](https://arxiv.org/html/2410.09649v1) |
| **Attention Is All You Need** | The seminal paper introducing the Transformer architecture, which uses self-attention and forms the foundation for virtually all modern large language models. | 2017-06 | [https://arxiv.org/abs/1706.03762](https://arxiv.org/abs/1706.03762) |
